# ColdX Droogijs Landing Page

GitHub Pages-ready landing page voor ColdX Dry Ice.

## Bestanden
- `index.html` – complete landingspagina
- `styles.css` – responsive styling
- `assets/coldx-brandboard.png` – aangeleverde ColdX visual

## Publiceren via GitHub Pages
1. Maak een nieuwe GitHub repository, bijvoorbeeld `coldx-droogijs`.
2. Upload alle bestanden met dezelfde mappenstructuur.
3. Ga naar **Settings → Pages**.
4. Kies **Deploy from a branch**.
5. Selecteer `main` en `/ (root)`.
6. Open de gegenereerde GitHub Pages-URL.

## Inhoud
De productinformatie is gebaseerd op de aangeleverde Marktplaatsadvertentie: 10 kg droogijs + EPS-doos voor €39,50, standaard 5/10/20 kg, pellets van 16 mm afhankelijk van voorraad en grotere hoeveelheden in overleg.
